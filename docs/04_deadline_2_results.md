# Проверка загрузки данных

Проверка выполнена 04.10.2026 командой:

```powershell
python -X utf8 -m src.ingestion.demo
```

Сначала загружен период 01.09.2024 — 31.08.2026, затем повторён тот же запуск и добавлен один день — 01.09.2026.

| Данные | Первая загрузка | Повтор | Добавление дня |
| --- | ---: | ---: | ---: |
| Позиции заказов | 237 259 | 237 259 | 237 537 |
| Снимки остатков | 21 900 | 21 900 | 21 930 |
| Календарные дни | 1 096 | 1 096 | 1 096 |
| Дни исторической погоды | 730 | 730 | 731 |
| Строки прогноза погоды | 7 | 7 | 7 |

При повторной загрузке количество записей не изменилось. За новый день добавились 278 позиций заказов, 30 снимков остатков и одна строка исторической погоды. Для каждого из 731 дней есть снимки всех 30 товаров, календарь и погода.

Календарь получен за 2024–2026 годы. Прогноз погоды получен на 04.10.2026 — 10.10.2026 в 20:00:44 МСК. Этот прогноз ещё не был доступен в 06:00 того же дня, что нужно учитывать при последующем построении модели.

За первую загрузку сделано 6 HTTP-запросов, за повтор — 0, при добавлении дня — 1. Ответы и время их получения сохранены. В журнале первой демонстрации 12 успешных операций: четыре загрузчика по три запуска.

Дополнительно проверен запуск без интернета по сохранённым ответам. Он прошёл успешно, количество записей не изменилось. Все 8 автоматических тестов тоже прошли: они проверяют генератор, повторную загрузку, ошибки API, сохранение версий ответов и откат неполного пакета.
